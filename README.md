# ექიმების დირექტორია (Telemedicine & Clinic Management System)

## პროექტის მიმოხილვა
ვებ-აპლიკაცია, სადაც პაციენტს შეუძლია ექიმების სიის ნახვა, სახელით ძიება და სპეციალობით ფილტრაცია.

## როლი
**სტუდენტი 1:** ლევანი [გვარი] — ექიმების დირექტორია და განრიგის ფილტრაცია

## Tech Stack
React (Vite), TypeScript, Tailwind CSS, Sass/SCSS, Fetch API (doctors.json), Git

## გაშვება
```bash
npm install
npm run dev     # დეველოპმენტი
npm run build   # პროდაქშენი (dist/)
```
